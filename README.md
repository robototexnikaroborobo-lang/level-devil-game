# Level Devil (HTML Demo)

This is a small browser-based platformer inspired by Level Devil. It includes:

- side-scrolling platform movement
- jumping and gravity
- fake doors that kill you
- disappearing platforms
- spike traps
- changing controls on one level
- progression across several levels

## Run it

Open `index.html` in a browser.

If you want to serve it locally with Python:

```bash
cd /path/to/your/project
python -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

## Controls

- Move: `A` / `D` or arrow keys
- Jump: `W`, `↑`, or `Space`
- Restart current level: `R`

## Notes

This is a lightweight prototype inspired by the mechanics of Level Devil, not a full clone.
